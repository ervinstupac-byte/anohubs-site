Frequency Regulation Fundamentals

Your Role in Grid Stability - 1.3 MW Units

The two 1.3 MW Francis units contribute to Rwanda National Grid frequency regulation through proportional load sharing.

Grid Frequency Basics

  • Nominal Frequency: 50.00 Hz (Rwanda grid standard)
  • Operating Tolerance: 49.8 - 50.2 Hz (±0.2 Hz)
  • Emergency Tolerance: 49.5 - 50.5 Hz (±0.5 Hz)
  • Load Rejection: If frequency > 50.5 Hz → Auto-disconnect to prevent overspeed

Frequency-Load Relationship

System Response:

  • Grid frequency drops (< 50 Hz) → System needs MORE power → Your governor OPENS guide vanes → Your MW increases
  • Grid frequency rises (> 50 Hz) → System has TOO MUCH power → Your governor CLOSES guide vanes → Your MW decreases
Droop Settings - The 4-6% Rule

What is Droop?

Definition: The percentage frequency change required for the governor to move from 0% to 100% power output.

Formula:

Droop (%) = (Δf / f_nominal) × 100

Where:

  • Δf = Frequency change from no-load to full-load (Hz)
  • f_nominal = 50 Hz

Example for 4% Droop:

  • Δf = 0.04 × 50 = 2.0 Hz
  • At 50.0 Hz → Unit runs at rated MW (1.3 MW)
  • At 48.0 Hz → Unit tries to deliver maximum power (governor fully open)
  • At 52.0 Hz → Unit tries to deliver zero power (governor fully closed)

Why Droop is Critical for Load Sharing

Problem Without Droop (0% Droop = Isochronous Mode):

  • Governor tries to maintain EXACTLY 50.00 Hz
  • With two units in parallel, both fight to control frequency
  • Result: "Governor fighting" - units oscillate wildly between overload and underload
  • ⚠️ THIS MODE IS ONLY FOR ISLAND OPERATION (ONE UNIT ONLY)

Solution: Proportional Droop (4-6%):

  • Each unit responds proportionally to frequency deviation
  • Load is naturally shared based on unit size and droop setting
  • Both units can run in parallel without fighting

⚠️ Critical Rule for Your 1.3 MW Units:

Operating Mode Droop Setting Reason
Parallel with Rwanda Grid 4-6% Allows stable load sharing with other grid generators
Parallel with Each Other (Unit 1 + Unit 2) 4-6% (SAME on both) Equal droop = equal load sharing between units
Island Mode (Emergency) 0% (Isochronous) ONE unit controls frequency exactly (other unit OFF)
The Vortex Correlation - Rough Running Zones

How Draft Tube Vortex Affects Frequency Stability

Physical Mechanism:

  1. At part-load (40-70% MW), draft tube vortex rope forms → Low-frequency pulsing (0.2-2 Hz)
  2. Vortex causes cyclic pressure fluctuations in draft tube
  3. Pressure fluctuations translate to torque pulsations on runner
  4. Torque pulsations cause shaft speed oscillations (±0.1 Hz)
  5. Governor "sees" frequency oscillate → Tries to correct → Guide vanes move erratically
  6. Result: "Hunting" behavior even with perfect PID settings

Rough Running Zone Map

Load Range (MW) % of Rated Vortex Status Governor Behavior
0 - 0.5 MW 0 - 40% Strong vortex Severe hunting - AVOID
0.5 - 0.9 MW 40 - 70% Moderate vortex Acceptable with air admission
0.9 - 1.3 MW 70 - 100% No vortex Stable operation

Mitigation Strategy:

  • Air Admission Valve: Inject compressed air into draft tube cone → Breaks up vortex rope → Reduces pulsations
  • Optimal Air Flow: 1-2% of water flow (approx 0.5-1.0 m³/s air)
  • Cross-Reference: See Vortex Control SOP and Draft Tube Air Admission SOP
Response Time Tuning - Dead-Time Analysis

Understanding Dead-Time

Definition: The time delay between a frequency shift detection and the start of guide vane movement.

Components of Dead-Time:

  1. Sensor Lag: Frequency sensor averaging time (typical: 100-200 ms)
  2. Governor Processing: PID calculation time (typical: 50-100 ms)
  3. Hydraulic Lag: Oil pressure buildup in servomotor (typical: 200-500 ms)
  4. Mechanical Backlash: Play in linkage pins before actual movement (typical: 50-100 ms)

Total Dead-Time: Typically 400-900 ms for your units.

How to Measure Dead-Time:

  1. With unit running at 1.0 MW, 50.0 Hz (stable)
  2. Command a manual load change: Increase setpoint by 0.1 MW
  3. Using oscilloscope or SCADA trending:
    • Channel 1: Frequency signal (Hz)
    • Channel 2: Guide vane position (%)
  4. Trigger on frequency drop event
  5. Measure time from frequency drop start to first guide vane movement

Target Dead-Time:

  • Good: < 500 ms (responsive system)
  • Acceptable: 500-800 ms (typical for mechanical governors)
  • Poor: > 800 ms (investigate oil aeration, linkage play) → See Oil Health SOP
Island Mode vs. Parallel Operation

Critical Logic Differences

Parallel Operation (Normal)

Configuration: Units connected to Rwanda national grid OR both 1.3 MW units synchronized together.

Parameter Setting Reason
Droop 4-6% Proportional load sharing
Governor Mode Speed Droop Follow grid frequency
Dead-Band ±0.05 Hz Prevent excessive vane movement
Auto Load Control Disabled Grid controls load via frequency

Island Mode (Emergency Only)

Configuration: One unit powering isolated local load ONLY. Other unit OFF. Grid disconnected.

Parameter Setting Reason
Droop 0% (Isochronous) Maintain exact 50.00 Hz
Governor Mode Speed Control Unit IS the frequency reference
Dead-Band ±0.01 Hz Tight frequency control needed
Auto Load Control Enabled Match load to generation capacity

Transition Procedure (Grid → Island)

⚠️ MANUAL PROCEDURE REQUIRED - NO AUTO-SWITCHOVER

  1. Open main circuit breaker to disconnect from Rwanda grid
  2. Stop Unit 2 if both units are running (only ONE unit in island mode)
  3. Set Unit 1 governor to Isochronous (0% droop)
  4. Enable Auto Load Control
  5. Reduce local load to match unit capacity (max 1.3 MW)
  6. Monitor frequency: Should stabilize at 50.00 ± 0.05 Hz within 30 seconds

⚠️ Risk: If local load exceeds 1.3 MW in island mode, unit will overload and trip on frequency drop (< 49.0 Hz). Load shedding MUST be performed before transition.

Diagnostic Procedures

Governor Response Test (Step Response)

Purpose: Verify governor response time and stability.

  1. Run unit at 1.0 MW (75% load), stable frequency 50.0 Hz
  2. Command 10% step change: Increase setpoint to 1.1 MW
  3. Record:
    • Time to first response (dead-time)
    • Time to reach new setpoint (settling time)
    • Overshoot (if any)

Acceptance Criteria:

  • Dead-Time: < 500 ms
  • Settling Time: < 10 seconds
  • Overshoot: < 5% of step size (< 0.05 MW for 0.1 MW step)

Frequency Stability Test

  1. Run unit synchronized to grid at 1.2 MW for 1 hour
  2. Record frequency every 1 minute
  3. Calculate standard deviation (σ) of frequency

Acceptance:

  • Good: σ < 0.02 Hz (very stable)
  • Acceptable: σ < 0.05 Hz
  • Poor: σ > 0.05 Hz → Investigate hunting, vortex, or oil aeration issues
